Bot avatars (`<avatar>` from each profile in the repo-level `bots` folder).

The included files are placeholders generated by `tools/avatars/make_avatars.py`
(validated with the Khronos glTF validator). Replace any of them with a better
model of the same name. Keep these animation names, which the app plays by state:
`idle`, `sleep`, `look_at_user`, `listen`, `think`, `talk`, `work`, plus the bot's
`signatureMoves`. A model without a matching animation falls back to `idle`.
